### Игра маджонг для внутреннего спокойствия
с любовью для nfactorial

Из функционала - самая обыкновенная и ничем не примечательная игра Маджонг, но включающая в себя технологии по отслеживанию стресса, а также использующая методологии для его снижения. Например: музыкальное сопровождение (успокаивающие звуки, красивый фон с приятными анимациями), подключение устройства (смарт-часы, смарт-кольцо, смарт-что то ещо) с возможностью следить за своим пульсом, ну и ненавязчивые рекомендации по дыхательной практике прямо во время игры. Всё это гарантирует спокойствие ваших нервов и ещё нескольких ваших коллег по опен-спейсу.

---

- **Что сделано** - маджонг, который замечает что игрок начал нервничать (по кликам или по пульсу с BLE-устройства) и мягко подкидывает ему дыхательную практику, спокойный звук и красивый культурный фон с мягкими анимациями.
- **Для кого** - ВСЕ! ДЛЯ ВСЕХ!!! А кому сейчас легко?! Ну а так это отличное место где можно убить время, и успокоить нервишки. самое то для фаундеров))) кроме убития времени, у них его и так нет. Подойдет как для школьников так и для людей в возрасте
- **Почему это ценно** - Это ценно потому что моя работа не похожа на все маджонги, здесь собраны - атмосфера, методики, что уже превращает игру в инструмент, когда это действительно важно, ведь мало кто задумывается над психологическим здоровьем, но иногда следует об этом вспоминать

### Как запустить

```bash
git clone <repo-url>
cd mahjong_nf
npm install
```

Создайте `.env.local` (значения из Supabase Dashboard → Settings → API):

```env
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

Дальше:

```bash
npm run dev    # http://localhost:3000 — игра, статистика, рейтинг
npm run build  # production build
npm run lint   # проверить, что я не оставил unused imports
```

Для пульсометра нужен Chrome / Edge / Brave с разрешённым Bluetooth и работающим BLE-адаптером. Firefox и Safari пока (и в обозримом будущем) Web Bluetooth не поддерживают - это к ним вопросы, не к нам.
